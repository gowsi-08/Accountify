# 📎 Attachments Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Add a Transaction
```
1. Go to Transactions page
2. Click "Add Transaction" button
3. Fill in the details (amount, date, category)
```

### Step 2: Upload Receipt
```
1. Scroll to "Attachments" section
2. Click "Upload Receipt/Document"
3. Select your image or PDF file
4. Wait for "✅ File uploaded successfully"
```

### Step 3: Save & View
```
1. Click "Add" to save transaction
2. See attachment badge (📎 1) in table
3. Click badge to view/download files
```

---

## 📋 Supported Files

### ✅ Allowed
- **Images**: JPG, JPEG, PNG, GIF
- **Documents**: PDF
- **Max Size**: 5MB per file

### ❌ Not Allowed
- Videos (MP4, AVI, etc.)
- Audio (MP3, WAV, etc.)
- Documents (Word, Excel, etc.)
- Archives (ZIP, RAR, etc.)

## 🔧 Quick Actions

### Upload File
```
Transaction Modal → Attachments → Upload → Select File → Wait
```

### View Attachments
```
Transactions Table → Click 📎 Badge → View All Files
```

### Download File
```
Attachment Viewer → Click Download Button → File Opens
```

### Delete File
```
Transaction Modal → Attachments → Click X → Confirm
```

## ⚠️ Troubleshooting

### File Won't Upload?
- ✅ Check file size (< 5MB)
- ✅ Check file type (image or PDF)
- ✅ Check internet connection
- ✅ Verify GitHub is configured

### Can't See Attachment?
- ✅ Save transaction after upload
- ✅ Refresh the page
- ✅ Check GitHub repository

### Upload Too Slow?
- ✅ Compress image before upload
- ✅ Use smaller file sizes
- ✅ Check internet speed
