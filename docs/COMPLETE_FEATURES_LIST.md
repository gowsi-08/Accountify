## 14. 📎 **Attachments & Receipts** (NEW!)

### Attachment Features:
- ✅ **Upload files** to transactions (images & PDFs)
- ✅ **Multiple attachments** per transaction
- ✅ **File types**: JPG, PNG, GIF, PDF
- ✅ **Max file size**: 5MB per file
- ✅ **Storage**: Secure GitHub storage in `/receipts` folder
- ✅ **View attachments** - Dedicated viewer modal
- ✅ **Download files** - One-click download
- ✅ **Delete attachments** - Remove unwanted files
- ✅ **Image preview** - View images directly in app
- ✅ **File info** - Name, size, upload date
- ✅ **Attachment count** - Badge in transactions table
- ✅ **Mobile support** - Upload from phone camera

### How Attachments Work:
1. Add/Edit any transaction
2. Click "Upload Receipt/Document"
3. Select image or PDF (max 5MB)
4. File uploads to GitHub
5. View attachment count in table
6. Click badge to view all files
7. Download or delete anytime

### Attachment Use Cases:
- **Tax Records**: Upload invoices for deductions
- **Expense Claims**: Attach receipts for reimbursement
- **Warranty**: Store warranty cards and receipts
- **Medical**: Keep prescriptions and bills
- **Travel**: Save tickets and booking confirmations
- **Business**: Professional documentation

### Technical Details:
- Files stored in GitHub `/receipts` folder
- Unique naming: `{transactionId}_{timestamp}_{filename}`
- Base64 encoding for upload
- Download URLs cached
- Rate limit friendly (1 call per upload/download)

## 🚀 **How to Use Tags Right Now**

### Step-by-Step:

1. **Add a Transaction with Tags:**
   - Go to Transactions page
   - Click "Add Transaction"
   - Fill in details
   - Scroll to "Tags" field
   - Type "business" and press Enter
   - Type "tax-deductible" and press Enter
   - Click "Add"

2. **Filter by Tags:**
   - Go to Transactions page
   - Click "Filters" button
   - Find "Tag" dropdown
   - Select a tag (e.g., "business")
   - See all business transactions

3. **View Tag Analytics:**
   - Go to Reports page
   - Scroll to bottom
   - See "Tag-based Analytics" section
   - View spending per tag
   - See transaction counts

4. **Search with Tags:**
