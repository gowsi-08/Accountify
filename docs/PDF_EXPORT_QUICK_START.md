# 📄 PDF Export - Quick Start

## 🚀 3 Steps to Export

### Step 1: Go to Reports
```
Click "Reports" in sidebar
```

### Step 2: Click Export PDF
```
Click red "Export PDF" button (top-right)
```

### Step 3: Done!
```
PDF downloads automatically
File: financial_report_YYYY-MM-DD.pdf
```
